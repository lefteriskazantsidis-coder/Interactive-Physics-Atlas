# Interactive Physics Data Atlas

An interactive visualisation of fundamental physical constants and the
phenomena they govern, built as a browser application.

**Live demo:** [https://lefteriskazantsidis-coder.github.io/REPO-NAME/](https://github.com/lefteriskazantsidis-coder/Interactive-Physics-Atlas/)

**Built with:** JavaScript, HTML5 Canvas, SVG — no frameworks, no build step.

Developed with AI assistance; design decisions my own.
